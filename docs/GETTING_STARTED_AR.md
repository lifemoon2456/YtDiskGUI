# دليل YTDISK لويندوز

هذا دليل للمستخدم الذي يريد استعمال التطبيق من دون معرفة Python أو سطر الأوامر.

> تنبيه: هذا مشروع تعليمي وتجريبي. لا تستخدم YouTube أو هذا التطبيق لحفظ ملفات مهمة أو كنسخة احتياطية وحيدة، والتزم بشروط أي خدمة تستخدمها.

## 1. ما الذي تحتاجه؟

- جهاز Windows 10 أو Windows 11 بنواة 64 بت.
- مساحة فارغة كافية؛ فيديو 4K الناتج قد يكون كبيرًا جدًا.
- FFmpeg، ويكفي تثبيته مرة واحدة لكل جهاز.
- نسخة التطبيق المطابقة لجهازك، وفيديو YTDISK إذا كنت ستسترجع ملفًا.

## 2. التثبيت لأول مرة

1. من صفحة GitHub اختر **Releases** ثم نزّل `YTDISK-windows-x64.zip`.
2. انقر بزر الفأرة الأيمن على الملف واختر **Extract All / استخراج الكل**.
3. افتح PowerShell واكتب الأمر التالي لتثبيت FFmpeg:

   ```powershell
   winget install --id Gyan.FFmpeg -e
   ```

4. أغلق PowerShell وافتحه من جديد، ثم تحقق:

   ```powershell
   ffmpeg -version
   ```

5. افتح `YTDISK.exe`. أبقِ مجلد `_internal` بجانبه دائمًا؛ لا تنقل EXE وحده إلى سطح المكتب.

إذا منع Windows تشغيل التطبيق، افحص أن الملف جاء من صفحة الإصدار الرسمية، ثم اختر **More info / مزيد من المعلومات** و**Run anyway / تشغيل على أي حال** فقط إذا كنت تثق في مصدره.

## 3. إنشاء فيديو من ملف

1. افتح تبويب **إنشاء فيديو**.
2. عند «الملف»، اختر الملف المطلوب.
3. عند «الفيديو الناتج»، اختر اسمًا ومكانًا مثل `D:\Videos\my-file.mp4`.
4. كلمة المرور اختيارية. إن وضعتها، احتفظ بها؛ لا يمكن استعادة الملف من دونها.
5. اترك حجم البلوك `4 × 4` وتصحيح الأخطاء `32` في أول تجربة.
6. اختر **إنشاء فيديو 4K** وانتظر حتى تظهر رسالة النجاح.

لا تغلق البرنامج أو تطفئ الجهاز أثناء المعالجة.

## 4. استرجاع ملف من فيديو

1. افتح تبويب **استرجاع ملف**.
2. اختر فيديو YTDISK.
3. اختر مجلدًا جديدًا أو فارغًا للحفظ.
4. أدخل كلمة المرور إن كان الملف شُفّر عند الإنشاء.
5. اختر **استرجاع الملف**.

يتحقق التطبيق من SHA-256 في النهاية. رسالة النجاح تعني أن الملف المسترجع مطابق للملف الأصلي بايتًا ببايت.

## 5. تبادل فيديو بين جهازين أو شخصين

لا يلزم أن تكون أسماء المستخدمين أو مسارات المجلدات أو مواصفات الجهازين متطابقة. بيانات الاسترجاع الأساسية (اسم الملف، حجمه، إعدادات البلوك والحماية) موجودة داخل رأس الفيديو نفسه.

| عند المُرسِل | عند المُستلم |
|---|---|
| ينشئ فيديو MP4 من الملف. | يثبت FFmpeg ويفك ضغط نفس إصدار التطبيق أو إصدار أحدث متوافق. |
| يرسل **ملف الفيديو الأصلي** كملف، عبر فلاش USB أو مساحة سحابية أو وسيلة لا تعيد ضغطه. | ينزّل/ينسخ الفيديو كاملًا، ثم يسترجعه إلى مجلد يختاره. |
| يشارك كلمة المرور — إن وجدت — عبر قناة منفصلة وآمنة. | يدخل كلمة المرور نفسها تمامًا. |

### عند استخدام YouTube

- ارفع الفيديو كـ **Unlisted** على قناة تجريبية فقط، وانتظر حتى تتوفر دقة 2160p (4K).
- يجب على المستلم تنزيل مسار فيديو بدقة 2160p أو أعلى؛ تنزيل 1080p لن يكون كافيًا عادةً.
- لا ترسل الفيديو كمقطع عبر تطبيقات الدردشة أو الشبكات الاجتماعية التي تعيد ضغط الفيديو. أرسله كـ **ملف** أو رابط تنزيل للملف الأصلي.

### ملاحظات التوافق

- نسخة EXE الحالية تعمل على Windows x64. على macOS أو Linux استخدم الكود المصدر واتبع متطلبات Python وFFmpeg.
- من الأفضل أن يستخدم الطرفان نفس إصدار التطبيق، خصوصًا عند ظهور إصدار جديد يغيّر صيغة الفيديو.
- لا يحتاج المستلم إلى الملف الأصلي أو إلى معرفة إعدادات البلوك وReed-Solomon؛ يقرأها التطبيق من الفيديو.
- لا يمكن استرجاع ملف مشفّر من دون كلمة المرور. لا توجد «طريقة استعادة» لكلمة مرور مفقودة.

## 6. حل المشاكل السريعة

| المشكلة | ما الذي تفعله؟ |
|---|---|
| رسالة أن FFmpeg غير موجود | ثبّته بالأمر في الخطوة 2، ثم أعد فتح التطبيق. |
| التطبيق لا يبدأ بعد نقله | أعد فك ضغط ملف الإصدار كاملًا، ولا تفصل `YTDISK.exe` عن `_internal`. |
| فشل الاسترجاع أو ظهر `Reed-Solomon gave up` | تأكد أنك تستخدم الفيديو الأصلي أو نسخة 2160p من YouTube، وأعد تنزيله إن لزم. |
| `decryption failed` | كلمة المرور خاطئة أو الفيديو تضرر. تحقق منها حرفًا بحرف. |
| المساحة غير كافية | اختر قرصًا آخر؛ الفيديو الناتج قد يحتاج مساحة كبيرة. |

## للمطورين: البناء من المصدر

```powershell
git clone <رابط-مستودعك>
cd YtDisk
pip install -r requirements-build.txt
.\build-windows.ps1
```

ارفع **محتويات** `dist\YTDISK` في ملف ZIP باسم واضح مثل `YTDISK-windows-x64.zip`. لا ترفع مجلدي `build` أو `dist` مباشرة إلى Git.
